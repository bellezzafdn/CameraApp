# Camera Magic App

This is a SwiftUI‑based iOS project that implements the *iOS Camera Magic* trick described earlier.

## Project structure
```
CameraApp/
├─ CameraApp.xcodeproj          # Xcode project (to be generated by Xcode when you add the files)
├─ Sources/
│   ├─ AppDelegate.swift
│   ├─ MagicCameraApp.swift      # @main entry point
│   ├─ ContentView.swift
│   ├─ BlurOverlayView.swift
│   ├─ CameraView.swift
│   ├─ ARSceneView.swift
│   ├─ PrewarmManager.swift
│   ├─ CameraService.swift
│   ├─ VisionProcessor.swift
│   ├─ ARService.swift
│   ├─ FilterManager.swift
│   └─ MotionService.swift
└─ Resources/
    ├─ sixFlowers.usdz
    ├─ sixStars.usdz
    └─ sixHearts.usdz
```

## How to get started
1. Open Xcode → *Create a new iOS App* → **SwiftUI** → name it **CameraApp**.
2. Replace the automatically generated files with the ones provided in `Sources/`.
3. Add the three USDZ assets in the **Resources** folder (drag‑and‑drop into the Xcode project, ensure *Copy items if needed* is checked).
4. Enable the following capabilities in your signing profile:
   - **Camera**
   - **ARKit**
   - **Background Modes → Audio, AirPlay, and Picture in Picture** (required only for the pre‑warm session; you can disable it later).
5. Build and run on a real iPhone 18 Pro (the AR features require a device, not the simulator).

The code implements:
- **Pre‑warm** of `AVCaptureSession` and `ARSession` while the app is in the background.
- **Rectangle detection** via Vision (`VNDetectRectanglesRequest`).
- **AR overlay** of a randomly chosen filter (6‑flowers, 6‑stars, 6‑hearts).
- **Shake detection** to remove the filter.
- **Blur overlay** mimicking the native camera blur.

Feel free to explore the source files for detailed implementation notes.
